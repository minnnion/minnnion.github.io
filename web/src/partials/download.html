After install

Updates look after themselves

Updates itself

  • The app checks GitHub Releases for new versions
  • Each update is checked against GitHub's SHA-256, and the app refuses one that doesn't match
  • Plugins update from the Marketplace page

Check the file

  • Every release lists a SHA-256 checksum
  • In PowerShell, run Get-FileHash .\setup.exe and compare

Every release

  • Older versions stay on GitHub Releases
  • Each one has release notes
  • Uninstall from Windows Settings, Apps
Questions

Installing

Can I pick a different use later?

Yes. Add the other plugins any time from the Marketplace page in the app.

Does setup need the internet?

Yes, it downloads the plugins for the use you pick. After that, the PC and phone talk over your own network.
